# Book_Management_System

**项目介绍：** 基于C语言实现的简易版图书管理系统，采用**顺序存储（结构体数组）**实现，控制台交互版本。

**🎯项目目的：**

1. 巩固C语言基础语法，熟练掌握结构体、数组、循环分支等语法
2. 练习顺序表（顺序存储）的基础增删改查算法。
3. 为后续学习链表打下基础

**🛠️开发环境：**

- 编程语言：C
- 开发工具：VS2026、git
- Windows 11

## **核心功能介绍**

1. **添加书本功能：** 录入ISBN、书名、价格信息。

2. **查找书本功能：**支持ISBN编号查找。

3. **删除书本功能：**支持ISBN编号删除。

4. **修改书本功能：**根据ISBN编号选中指定图书。

5. **按价格排序书本功能：**采用选择排序，按照图书价格升序。

6. **显示全本图书：**遍历数组，格式化打印所有图书信息。

   

   ## 📌 学习收获 & 不太熟练的地方

   1. 对 `typedef` + `struct` 结构体类型定义语法不熟练，一开始分不清结构体标签和别名。

   **✨ 后续优化方向（拓展计划）**

   - 增加文件读写，实现数据持久化，达到关闭程序数据不丢失

   - 改为动态数组 / 链表存储，摆脱固定容量上限

   - 增加借书、还书、库存管理功能

   - 增加简单登录权限

     **📜 总结**：

  这个项目是 C 语言阶段的综合练手项目，把结构体、数组、函数、分支循环全部结合起来。虽然是简易内存版，但是完整跑通了顺序表的核心逻辑，为后面数据结构学习打好基础。
